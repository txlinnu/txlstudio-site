TXL Cloud

Local-first · unlimited

A private alternative to hosted AI chat products. Same UX pattern as the big names — accounts, persistent history, projects, artifacts — but the model runs on hardware you control. No per-day cap, no message ever leaves the machine.

  • Dual-backend inference — Groq for hosted, local Ollama (Qwen2.5 7B/14B) for private, chosen at startup, zero code duplication
  • Windows installer auto-detects RAM/GPU and only pulls the 14B model on machines that can run it
  • Per-account "Projects" with file upload + TF-IDF retrieval — no embeddings model needed
  • Sandboxed "Code mode" agent: reads/writes files, runs shell commands, fetches URLs — with human approval before any write or command executes
  • Shareable chat links, long-term memory, live Artifacts viewer for HTML/SVG
  • Streamed responses end-to-end via Flask's stream_with_context

// under the hood

Both ship as real desktop apps, not browser shortcuts

01

Hardware-aware install

The NSIS installer detects the machine's RAM and GPU before picking a model tier — no manual config, no crashing a 4GB laptop with a 14B model.

02

DPI-aware manifest

Fixed blurry native-text rendering on scaled Windows displays by embedding a proper DPI-aware manifest into the Electron build.

03

Session persistence bug

Login sessions weren't surviving reboots — traced to Chromium's batched cookie-store writes racing an app close. An app.quit()-based fix caused hangs; flushing on window-close instead solved it cleanly.
